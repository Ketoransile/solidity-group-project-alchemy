# Solidity Group Project Alchemy

This repository is for a Solidity group laboratory assignment. It is organized for collecting course materials, individual practice work, screenshots, and the final shared project.

## Course

Chosen course: Learn Solidity by Alchemy University.

Course link: https://www.alchemy.com/university/courses/solidity

Submission deadline: May 06, 2026

## Folder Structure

- `course-materials/` - Shared notes, slides, and resource links.
- `code/` - Individual folders for each team member's Solidity practice code.
- `screenshots/` - Individual folders for screenshots and proof of work.
- `final-project/` - Shared final project contracts, scripts, and documentation.

Each team member has these code sections:

- `basics/` - Beginner Solidity exercises.
- `intermediate/` - Intermediate Solidity exercises.
- `projects/` - Personal mini-projects or experiments.

Empty folders are preserved with `.keep` files until real content is added.
